# Standard Operating Procedures (SOP) - Studio Quality & Approval Control

## 1. Product Ingestion & File Payload Standards
- All digital products generated by AI Creator Agents must be placed into `catalog/raw_ingest/{category}/{product_name}/`.
- Folder structure must contain:
  1. `payload.zip` or primary deliverable asset file.
  2. `info.json` (optional preliminary metadata, e.g. title, category, target pricing).

## 2. Quality Control & Approval Workflow
1. **Deduplication Check**: System automatically checks payload hash against registry. Duplicates are rejected with log warning.
2. **SEO & Metadata Enrichment**: Automated generation of 140-char title, 13 Etsy tags, pricing tier, and PDF user guide.
3. **Multi-Card Thumbnail Generation**: System auto-generates 5 standard 2700x2025 preview slides.
4. **Approval Gatekeeper**:
   - Status defaults to `pending_approval`.
   - Human Studio Director reviews items in the Web Dashboard or CLI.
   - Upon clicking **Approve**, status moves to `approved` and queues for publishing.

## 3. Marketplace Publishing Protocol
- Products are published automatically to enabled marketplaces (Etsy, Gumroad, Lemon Squeezy, Direct Web) upon approval.
- Any network error triggers an `error` flag for that specific channel without blocking other channel deployments.
